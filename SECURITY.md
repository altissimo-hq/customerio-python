# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please email the maintainers directly or use
[GitHub's private vulnerability reporting](https://github.com/altissimo-hq/customerio-python/security/advisories/new).

We will acknowledge receipt within 48 hours and provide a more detailed response within 5 business days.
